## 1. Overview

This repository contains the production source code for **Soumya Kumar's personal portfolio (Version 2.0)**. 

Soumya is a Computer Science and Engineering undergraduate at **Sri Venkateswara College of Engineering (SVCE, Class of 2028)**. Her work bridges distributed software engineering, machine learning threat heuristics, and studio-grade visual design systems.

The platform is designed to give technical recruiters and creative directors an evidence-backed exploration of her capabilities—moving past generic templates to provide architectural case studies, transparent algorithms, and original brand identity assets.

## 2. Design Philosophy

The visual language follows a Swiss-inspired editorial design system characterized by disciplined contrast, typographic pacing, and restrained metallic details:

- **Deep Pine (`#0E1613`)**: Primary atmospheric substrate evoking low-glare dark workstations and architectural depth.
- **Champagne Ivory (`#F4EDE4`)**: High-contrast editorial display typography and warm canvas surfaces.
- **Muted Sage (`#9BB0A5`)**: Technical telemetry, active state beacons, and data highlight badges.
- **Brushed Metallic Silver (`#B5B5AD`)**: Refined borders, orbital rings, and vector monogram marks.
- **Typography Matrix**: `DM Serif Display` for high-impact mastheads, `Inter` for dense user interface grids, and `JetBrains Mono` for architectural metadata and coordinates.

## 5. Technology Stack

- **Core Framework**: React 18.3, TypeScript 5.2
- **Build Engine & Bundler**: Vite 5.4, PostCSS, Autoprefixer
- **Styling & Tokens**: Tailwind CSS 3.4 with custom theme extensions
- **Animation & Transitions**: Framer Motion 11.3 (spring physics, reduced-motion compliant)
- **Vector Icons**: Lucide React 0.447
- **Routing**: React Router DOM 6.26 with hash-scroll restoration
- **Typography Fonts**: `@fontsource/dm-serif-display`, `@fontsource/inter`
- **Linting & Code Quality**: ESLint 8.57, TypeScript strict mode

---

## 6. Core Platform Features

1. **Dual Discovery Pathways**: Immediate orientation on the hero masthead allowing hiring teams to explore either Path A (Engineering) or Path B (Design).
2. **Interactive Project Atlas**: Search and filter engine querying all 10+ engineering systems and brand identities by keyword, discipline, status (`COMPLETED`, `PROTOTYPE`, `ACADEMIC`), and technology.
3. **15-Part Case Study Framework**: In-depth project documentation across architecture modules, testing metrics, challenges faced, and trade-off rationales.
4. **Visual Design Archive**: High-resolution gallery featuring authentic Canva and vector assets with direct external links to Behance case studies.
5. **Project-Mapped Skill Constellation**: 8 skill categories linking verified technical proficiencies directly to the repositories where they were implemented.
6. **Accessible Infrastructure**: WCAG 2.1 AA keyboard focus rings, skip-to-content anchor, semantic HTML landmarks, custom 404 page, and valid XML sitemap.

## 8. Local Development & Installation

### Prerequisites
- Node.js (v18.0.0 or higher recommended)
- npm (v9.0.0 or higher)

### Installation
```bash
# Clone the repository
git clone https://github.com/kusoumya2006-netizen/portfolio.git

# Navigate into the project directory
cd portfolio

# Install dependencies
npm install
```

### Development Server
```bash
# Start Vite development server with Hot Module Replacement (HMR)
npm run dev
```
Open your browser at `http://localhost:5173`.

### Code Quality & Linting
```bash
# Run ESLint validation across all TypeScript and TSX files
npm run lint
```

### Production Build
```bash
# Typecheck and bundle assets for production
npm run build
```
Compiled static assets are generated in the `dist/` directory.

### Preview Production Build
```bash
# Preview the production build locally
npm run preview
```
