# Soumya Kumar — Creative Technologist & CSE Portfolio

> **"A different state of thinking."**  
> Engineering logic meets creative instinct, quantum inquiry, brand architecture, and interactive design.

A bespoke, editorial portfolio web application for **Soumya Kumar** (B.E. Computer Science and Engineering, Sri Venkateswara College of Engineering · Class of 2028).

---

## ✦ Design Philosophy & Visual Language

- **Palette**: Deep Pine (`#0e1613`), Champagne Ivory (`#f4ede4`), Muted Sage (`#9bb0a5`), and Brushed Metallic Silver.
- **Typography**: Editorial serif headings paired with clean geometric monospace and sans-serif telemetry.
- **Interaction Model**: Kinetic typography, physics-based spring animations, floating orbital geometry, and custom SVG monograms.
- **Accessibility & Performance**: Fully keyboard accessible (WCAG 2.1 AA compliant), skip-to-content navigation, responsive grid layouts, and zero runtime layout shifts.

## ✦ Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or pnpm

### Installation
```bash
git clone https://github.com/kusoumya2006-netizen/portfolio.git
cd portfolio
npm install
```

### Development Server
```bash
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
